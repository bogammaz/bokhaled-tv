# قنوات الوالد - Android TV

تطبيق تلفزيون بسيط مصمم للريموت:
- القنوات مربعات كبيرة.
- التقسيمات في الأعلى.
- قسم "الكل" لكل القنوات.
- قسم "الأخبار" يجمع القنوات الإخبارية العربية الموجودة بالقائمة.
- زر OK يفتح القناة فل سكرين.
- زر Back يرجع للقائمة.
- زر OK داخل المشغل يوقف/يكمل التشغيل.

الملف `app/src/main/assets/channels.m3u` يحتوي القنوات المجانية/العامة المضافة للتطبيق.

ملاحظة: بعض روابط البث العامة قد تتغير أو تكون محجوبة جغرافياً.
